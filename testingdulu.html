URL Display Probe

Checks how the host app renders a hostname in its URL bar: truncation, IDN/punycode policy, userinfo stripping. The page does not need to load — the toolbar string is the whole observation.

Cases T1/T2 need wildcard DNS on a domain you own to serve content. For detection they work without it — if the toolbar renders the crafted host before failing, the display flaw is already proven. Record what the toolbar shows even when the page errors.
